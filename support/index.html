Meditize helps reduce eye strain and build healthier screen habits with guided exercises and reminders.

Chrome Web Store: Download Meditize Extension for Chrome

How to install the extension

  1. Open the Chrome Web Store page.
  2. Click Add to Chrome.
  3. Confirm by clicking Add extension.
  4. Optional — pin Meditize to your Chrome toolbar: click the puzzle icon (Extensions), find Meditize, click the pin icon.
  5. Open the extension and allow notifications (recommended).

How to remove (uninstall) the extension

Option A — from the toolbar:

  1. Right-click the Meditize icon in the Chrome toolbar.
  2. Click Remove from Chrome.
  3. Confirm removal.

Option B — from the Extensions page:

  1. Open chrome://extensions/
  2. Find Meditize.
  3. Click Remove and confirm.

How to disable the extension (without deleting)

  1. Open chrome://extensions/
  2. Find Meditize.
  3. Turn off the extension toggle.

You can enable it again anytime.

Common issues and quick fixes

Extension does not appear after install

  • Open chrome://extensions/ and check if Meditize is enabled.
  • Click the Extensions (puzzle) icon and pin Meditize.
  • Restart Chrome.

Reminders are not showing

  • Allow notifications for Chrome in browser and system settings.
  • Check reminder settings inside Meditize.
  • Restart Chrome.

Extension UI does not load

  • Refresh the tab.
  • Restart Chrome.
  • Temporarily disable other extensions (possible conflict).
  • Reinstall Meditize.
